Webhooks

A webhook is an address on your own system. When something happens to one of your lessons or certificates, this server sends it a short message (a POST with JSON), so your system can react: publish a lesson when it is ready, tell an editor that captions changed, and so on.

    Its secret

    Copy it now: it is shown only once. Each message has a header X-DB-Signature: sha256=…, the HMAC-SHA256 of the body made with this secret. Check it to know the message came from us.

    How to check a message (Node.js example) 
    import { createHmac, timingSafeEqual } from 'node:crypto';
// body: the raw request body (text), secret: the webhook's secret
const expected = 'sha256=' + createHmac('sha256', secret).update(body).digest('hex');
const given = req.headers['x-db-signature'] || '';
const ok = given.length === expected.length && timingSafeEqual(Buffer.from(given), Buffer.from(expected));
// The body is { "event": "lesson.ready", "time": "…", "data": { "lesson": "…" } }
